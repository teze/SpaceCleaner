# CleanMyMac 统一版 - 系统清理工具

一个完整的 macOS 系统清理工具，整合所有功能到一个应用中，使用纯 Swift + AppKit 构建。

## ✨ 特点

- 🎯 **功能完整**：7 大功能模块整合在一个应用
- 🚀 **轻量级**：约 300 KB，无需 Xcode 即可构建
- ⚡ **快速**：原生 AppKit，性能优异
- 🔒 **安全**：文件移到废纸篓，可恢复
- 🧹 **真正清理**：不只是扫描，可以真正清理文件
- 💰 **免费**：完全开源，无需付费
- 🎨 **现代化**：侧边栏导航，模块化设计

## 📦 快速开始

### 统一版（推荐）⭐
所有功能整合在一个应用中！

```bash
# 构建
./build-unified.sh

# 运行
./run.sh
```

或者直接双击 `build/CleanMyMac.app`

```

```

## 📖 使用说明

### 启动应用
```bash
./run.sh
```

或者双击 `build/CleanMyMac.app`

### 使用流程

1. **选择功能模块**
   - 左侧边栏选择要使用的功能
   - 智能扫描：一键扫描所有类别
   - Space Lens：可视化磁盘空间
   - 其他模块：针对性清理

2. **智能扫描**
   - 点击"开始扫描"
   - 等待扫描完成
   - 查看可释放空间

3. **Space Lens**
   - 点击"选择文件夹"
   - 选择要分析的目录
   - 查看树状图
   - 点击矩形深入探索

4. **系统垃圾/大文件/旧文件**
   - 点击"开始扫描"
   - 查看扫描结果（名称、大小、路径）
   - 选择要清理的项目（当前会清理所有扫描到的项目）
   - 点击"清理"按钮
   - 确认清理对话框
   - 等待清理完成
   - 查看清理结果（成功/失败统计）

## 🎉 最新更新（v1.1）

### ✅ 已修复
- **大文件扫描器**：修复了找不到文件的问题，现在可以正确扫描 > 100MB 的文件
- **旧文件扫描器**：修复了找不到文件的问题，现在可以正确扫描 > 30 天未使用的文件

### 🎉 新功能
- **真正的清理功能**：不只是扫描，现在可以真正清理文件
  - 文件会被移到废纸篓（可恢复）
  - 清理进度实时显示
  - 清理完成后显示成功/失败统计
  - 如果有失败项，会显示错误原因
  - 清理成功后自动刷新列表

### 📋 清理功能使用说明
1. 在任意清理模块（系统垃圾/大文件/旧文件）点击"开始扫描"
2. 等待扫描完成，查看扫描结果
3. 点击"清理"按钮
4. 在确认对话框中查看：
   - 将要清理的项目数量
   - 可释放的空间大小
   - 文件会被移到废纸篓的提示
5. 点击"清理"确认
6. 等待清理完成
7. 查看清理结果：
   - 全部成功：显示成功消息，列表清空
   - 部分失败：显示成功/失败数量和错误原因，自动重新扫描

详细更新日志请查看 `更新日志.md`
