# 空间管理工具 - 使用说明

## ✅ 构建成功！

你的 macOS 空间管理工具已经成功打包完成！

## 📦 应用位置

```
build/空间管理.app
```

## 🚀 如何运行

### 方法 1：双击打开
直接在 Finder 中找到 `build/空间管理.app`，双击运行。

### 方法 2：命令行打开
```bash
open "build/空间管理.app"
```

### 方法 3：直接执行
```bash
./build/空间管理.app/Contents/MacOS/空间管理
```

## 🎯 功能说明

### 当前功能
- ✅ **目录扫描**：选择任意文件夹进行空间分析
- ✅ **大小统计**：显示每个文件/文件夹的大小
- ✅ **百分比显示**：显示每个项目占总空间的百分比
- ✅ **可视化进度条**：用颜色和进度条直观显示占用情况
  - 🔴 红色：占用 > 20%
  - 🟠 橙色：占用 10-20%
  - 🟢 绿色：占用 < 10%
- ✅ **智能排序**：按大小从大到小排序
- ✅ **格式化显示**：自动转换为 KB/MB/GB 等易读格式

### 使用步骤
1. 启动应用
2. 点击"选择文件夹"按钮
3. 选择要分析的目录
4. 等待扫描完成
5. 查看分析结果

## 🔧 技术信息

- **语言**：Swift
- **框架**：AppKit (Cocoa)
- **最低系统**：macOS 13.0+
- **架构**：ARM64 (Apple Silicon)
- **应用大小**：约 136 KB

## 📝 重新构建

如果需要重新构建应用：

```bash
./build-simple.sh
```

## ⚠️ 首次运行提示

首次运行时，macOS 可能会显示安全警告（因为应用未经过 Apple 公证）。

解决方法：
1. 右键点击应用
2. 选择"打开"
3. 在弹出的对话框中点击"打开"

或者在终端中运行：
```bash
xattr -cr "build/空间管理.app"
```

## 🎨 界面说明

应用使用简洁的单窗口界面：
- 顶部：选择文件夹按钮和进度指示器
- 主区域：显示扫描结果的文本区域
- 结果显示：
  - 文件夹路径
  - 总大小和项目数
  - 前 50 个最大的文件/文件夹列表
  - 每个项目的图标、名称、大小、百分比和可视化进度条
