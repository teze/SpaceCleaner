# 空间管理工具 (SpaceManager)

一个现代化的 macOS 空间整理工具，使用 Swift + SwiftUI 构建。

## 功能特性

### ✅ 已实现
- **存储分析**：扫描并可视化目录空间占用
- 文件大小统计和百分比显示
- 直观的进度条和颜色编码
- 现代化的 macOS 原生界面

### 🚧 规划中
- **重复文件查找**：基于 hash 的重复文件检测
- **大文件扫描**：快速定位占用空间的大文件
- **智能清理**：临时文件和缓存清理

## 技术栈

- **语言**：Swift 5.0+
- **框架**：SwiftUI
- **最低系统**：macOS 13.0+
- **架构**：MVVM

## 项目结构

```
SpaceManager/
├── SpaceManagerApp.swift      # 应用入口
├── ContentView.swift           # 主视图
├── Models/
│   └── FileItem.swift         # 文件数据模型
├── Views/
│   ├── SidebarView.swift      # 侧边栏
│   └── StorageView.swift      # 存储分析视图
└── Services/
    ├── FileScanner.swift      # 文件扫描服务
    └── StorageAnalyzer.swift  # 存储分析器
```

## 如何运行

1. 使用 Xcode 打开 `SpaceManager.xcodeproj`
2. 选择目标设备为 "My Mac"
3. 点击运行按钮 (⌘R)

## 权限说明

应用需要以下权限：
- **文件访问**：读取用户选择的文件夹内容
- **非沙盒模式**：为了完整的文件系统访问能力
