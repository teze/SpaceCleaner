# CleanMyMac 风格系统清理工具

一个完整的 macOS 系统清理工具，复刻 CleanMyMac 核心功能，使用纯 Swift + AppKit 构建。

## ✨ 特点

- 🎯 **功能完整**：复刻 CleanMyMac 核心功能
- 🚀 **轻量级**：仅 200 KB，无需 Xcode 即可构建
- ⚡ **快速**：原生 AppKit，性能优异
- 🔒 **安全**：文件移到废纸篓，可恢复
- 💰 **免费**：完全开源，无需付费

## 📦 快速开始

### 方式 1：CleanMyMac 完整版（推荐）
```bash
# 构建
./build-cleanmymac.sh

# 运行
./run-cleanmymac.sh
```

### 方式 2：简化版空间分析工具
```bash
# 构建
./build-simple.sh

# 运行
./run.sh
```

## 📖 使用说明

### CleanMyMac 版本

1. **启动扫描**
   - 打开应用
   - 点击"开始扫描"按钮
   - 等待扫描完成（2-5 分钟）

2. **查看结果**
   - 左侧边栏查看分类统计
   - 主区域查看详细文件列表
   - 顶部显示总计和已选大小

3. **执行清理**
   - 选择要清理的项目（默认全选）
   - 点击"清理选中项"按钮
   - 确认后执行清理
   - 查看清理报告

### 简化版

1. **启动应用**
   - 双击 `build/空间管理.app`
   - 或运行 `./run.sh`

2. **扫描目录**
   - 点击"选择文件夹"按钮
   - 选择要分析的目录
   - 等待扫描完成

3. **查看结果**
   - 查看总大小和项目数
   - 浏览最大的文件/文件夹
   - 通过颜色和进度条快速识别大文件

## ⚠️ 首次运行

首次运行时可能会遇到安全提示，解决方法：

```bash
xattr -cr "build/空间管理.app"
```

或者：
1. 右键点击应用
2. 选择"打开"
3. 点击"打开"确认
