# CleanMyMac 风格系统清理工具

一个完整的 macOS 系统清理工具，复刻 CleanMyMac 核心功能，使用纯 Swift + AppKit 构建。

## ✨ 特点

- 🚀 **轻量级**：仅 136 KB，无需 Xcode 即可构建
- ⚡ **快速**：原生 AppKit，性能优异
- 🎯 **简单**：单文件架构，易于理解和修改
- 🔒 **安全**：只读操作，不会修改任何文件

## 📦 快速开始

### 构建应用
```bash
./build-simple.sh
```

### 运行应用
```bash
./run.sh
```

或者直接双击 `build/空间管理.app`

## 🎯 功能特性

### ✅ 已实现
- **目录扫描**：快速扫描任意文件夹
- **大小统计**：精确计算文件和文件夹大小
- **智能排序**：按大小从大到小自动排序
- **可视化显示**：
  - 🔴 红色进度条：占用 > 20%
  - 🟠 橙色进度条：占用 10-20%
  - 🟢 绿色进度条：占用 < 10%
- **格式化输出**：自动转换为 KB/MB/GB
- **异步扫描**：不阻塞 UI，流畅体验

### 🚧 规划中
- 重复文件检测
- 大文件快速定位
- 文件类型分析
- 导出报告功能

## 🛠 技术栈

- **语言**：Swift 6.0+
- **框架**：AppKit (Cocoa)
- **最低系统**：macOS 13.0+
- **架构**：ARM64 (Apple Silicon)
- **构建工具**：swiftc (无需 Xcode)

## 🔧 构建要求

- macOS 13.0 或更高版本
- Swift 命令行工具（通常随系统自带）
- 无需安装 Xcode

## 📖 使用说明

1. **启动应用**
   - 双击 `build/空间管理.app`
   - 或运行 `./run.sh`

2. **扫描目录**
   - 点击"选择文件夹"按钮
   - 选择要分析的目录
   - 等待扫描完成

3. **查看结果**
   - 查看总大小和项目数
   - 浏览前 50 个最大的文件/文件夹
   - 通过颜色和进度条快速识别大文件

## ⚠️ 首次运行

首次运行时可能会遇到安全提示，解决方法：

```bash
xattr -cr "build/空间管理.app"
```

或者：
1. 右键点击应用
2. 选择"打开"
3. 点击"打开"确认
